# ФАОП Навигатор · PWA

Статический сайт (HTML/CSS/JavaScript, без сервера, регистраций, паролей и внешних зависимостей). В состав входят 46 карточек учебных планов: 26 вариантов ФАОП НОО, 15 вариантов ФАОП ООО (18 таблиц с учётом дополнительных планов для 6.2 и 7) и 2 варианта ФАООП УО.

**Запуск на компьютере:** откройте `index.html` в браузере. Чтобы установить как PWA, нужен HTTPS или локальный сервер (само открытие файла не включает service worker).

**Размещение на GitHub Pages:** создайте публичный репозиторий, загрузите в его корень *содержимое* этого архива (index.html, data.js, app.js, style.css, sw.js, manifest.webmanifest и каталог assets/), затем в Settings → Pages выберите Deploy from a branch → main → /(root). Появится адрес вида `https://<username>.github.io/<repo>/`. Никаких токенов и переменных окружения не требуется. Сайт публичный: им может воспользоваться любой, знающий ссылку; ссылка не является механизмом ограничения доступа.

**Обновление данных:** числовые строки находятся в data.js, а оригиналы изображений — в `assets/originals/`. При обновлении статических файлов измените версию кэша в sw.js для своевременного обновления PWA.

**Важно:** данные носят информационный характер, не заменяют действующие нормативные документы, заключение ПМПК или индивидуальный учебный план. При сопоставлении разных уровней образования приложение показывает предупреждение. Σ — сумма недельных показателей по классам, а не годовые или суммарные учебные часы за весь период.

## Полный перечень и источники для добавленных вариантов

**ФАОП НОО (26 вариантов):** 1.1–1.4; 2.1–2.3; 3.1–3.4; 4.1–4.3; 5.1–5.2; 6.1–6.4; 7.1–7.2; 8.1–8.4.

**ФАОП ООО (15 вариантов):** 1.1, 1.2; 2.2.1, 2.2.2; 3.1, 3.2; 4.1, 4.2; 5.1, 5.2; 6.1, 6.2; 7; 8.1, 8.2. НЕ существуют в качестве самостоятельных вариантов ФАОП ООО: 3.3, 3.4, 4.3, 6.3, 6.4, 7.1, 7.2, 8.3, 8.4. Они присутствуют только в каталоге НОО.

**ФАООП УО:** варианты 1 и 2 — отдельная федеральная программа.

Важное отличие достоверности чисел:
- 31 прежняя карточка включает таблицы из предоставленных фотографий.
- НОО 8.4 содержит новую полную числовую таблицу из пункта 202.5 приказа 1023 (редакция № 495); у неё нет приложенного скана, но в карточке указан точный электронный нормативный источник.
- Другие добавленные варианты (НОО 1.1, 2.1, 3.1, 4.1, 5.1, 6.1, 7.1, 8.1 и ООО 1.1, 3.1, 4.1, 5.1, 6.1, 8.1) содержат **не отдельную особую числовую сетку варианта**, а *справочный базовый 5-дневный план ФОП* согласно отсылкам ФАОП; конкретная сетка может отличаться, определяется образовательной организацией. Приложение явно маркирует эту особенность и предоставляет ссылку на раздел нормативного текста. Не следует считать базовую сетку обязательной для каждого такого варианта.
